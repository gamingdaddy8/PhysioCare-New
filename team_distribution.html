🧠 Key Concepts for Exam
  • Pose Detection Pipeline: Camera → MediaPipe/ML Kit → 33 Landmarks → UnifiedPose
  • Joint Angle Calculation: cos(θ) = (BA⃗ · BC⃗) / (|BA⃗| × |BC⃗|) → arccos → degrees
  • Rep Counting State Machine: down → holding (3s) → up_done → rep counted!
  • Platform-specific: MediaPipe for Web (JS interop), ML Kit for Mobile (native on-device)
  • Why Supabase: PostgreSQL + built-in Auth + real-time subscriptions + Row Level Security

🧠 Key Concepts for Exam
  • Auth Flow: Landing → Login/Register → Supabase Auth → Create Profile → Role-based routing
  • Dual-Role Registration: User selects Patient or Therapist; Patients pick their assigned therapist
  • Supabase Auth: Uses supabase_flutter for email/password auth with session management
  • Appointment Lifecycle: pending → confirmed / rejected / cancelled
  • Availability System: Therapist sets weekly windows → system generates available time slots
  • Blocked Dates: Therapist blocks specific dates with reason → no slots generated for those days
  • Calendar Booking: Select date → see available slots → pick slot → submit with optional query
